# API базы знаний для Voice AI

Руководитель создаёт и публикует статьи в разделе «База знаний». IRIS хранит статьи в общей SQLite по `DATABASE_PATH`. После публикации Voice AI получает опубликованную версию. Сохранённые правки вступают в силу после повторной публикации. При архивировании статья сразу исчезает из поиска и становится недоступна по ID.

## Подключение

1. Для существующей базы выполните штатную миграцию IRIS. Для нового файла SQLite FastAPI создаст таблицу при запуске. [Миграция SQLite](DATA_MODEL.md#миграция-sqlite)
2. Сгенерируйте отдельный случайный токен, например командой `python -c "import secrets; print(secrets.token_urlsafe(32))"`. Передайте его IRIS в переменной окружения `IRIS_VOICE_KNOWLEDGE_TOKEN`, а сервису Voice AI через хранилище секретов. Используйте уникальный токен для этого API.
3. Отправляйте `Authorization: Bearer <токен>` и `Accept: application/json`. Для соединения между хостами используйте HTTPS. API поддерживает поиск и чтение опубликованных статей независимо от состояния Contact Center. [OpenAPI](../contracts/openapi.json)

## Поиск

`GET /api/v1/voice/knowledge/search`

| Параметр | Значение |
| --- | --- |
| `q` | Обязательная строка от 1 до 200 символов после обрезки пробелов. Например, `перезагрузка роутера`. |
| `category` | Необязательный код категории из таблицы ниже. |
| `limit` | От 1 до 20 результатов. По умолчанию 5. |
| `offset` | Число пропускаемых результатов. По умолчанию 0. |

Поиск разбивает запрос на слова и числа, ищет их в названии и тексте и учитывает совпадения частей слов. Регистр и различие между «е» и «ё» игнорируются. Результаты упорядочены по числу совпавших слов, затем по числу совпадений в названии и времени публикации. Для запроса из одной пунктуации и при отсутствии совпадений `items` будет пустым.

| Код | Категория |
| --- | --- |
| `company` | Компания, услуги и тарифы |
| `offers` | Акции и спецпредложения |
| `instructions` | Инструкции и регламенты |
| `troubleshooting` | Типовые проблемы и решения |
| `faq` | Частые вопросы |

В примерах `IRIS_URL` содержит адрес FastAPI, а `IRIS_VOICE_KNOWLEDGE_TOKEN` поступает из хранилища секретов.

```bash
curl -fsS --get "${IRIS_URL}/api/v1/voice/knowledge/search" \
  -H "Authorization: Bearer ${IRIS_VOICE_KNOWLEDGE_TOKEN}" \
  --data-urlencode 'q=перезагрузка роутера' \
  --data-urlencode 'category=troubleshooting' \
  --data-urlencode 'limit=3'
```

```json
{
  "items": [
    {
      "id": "b446c08d-e77d-4b35-955f-91d5e416d327",
      "title": "Перезагрузка роутера",
      "category": "troubleshooting",
      "excerpt": "Отключите питание роутера, подождите 30 секунд и включите его снова.",
      "published_at": "2026-11-28T09:00:00Z"
    }
  ],
  "limit": 3,
  "offset": 0
}
```

`excerpt` содержит первые 280 символов статьи. Если вернулось `limit` результатов, следующий запрос можно выполнить с `offset + limit`.

## Чтение статьи

`GET /api/v1/voice/knowledge/articles/{article_id}`, где `article_id` — UUID из поиска.

```bash
curl -fsS "${IRIS_URL}/api/v1/voice/knowledge/articles/b446c08d-e77d-4b35-955f-91d5e416d327" \
  -H "Authorization: Bearer ${IRIS_VOICE_KNOWLEDGE_TOKEN}"
```

```json
{
  "id": "b446c08d-e77d-4b35-955f-91d5e416d327",
  "title": "Перезагрузка роутера",
  "category": "troubleshooting",
  "body": "Отключите питание роутера, подождите 30 секунд и включите его снова.\nПодождите, пока загорится индикатор интернета.",
  "published_at": "2026-11-28T09:00:00Z"
}
```

`body` содержит полный текст, а `published_at` — время публикации в UTC. Для консультации запрашивайте полный текст после поиска. Успешные ответы передаются с `Cache-Control: no-store`. Статья может уйти в архив между поиском и чтением, и тогда чтение вернёт `404`.

| HTTP | Значение |
| --- | --- |
| `200` | Поиск выполнен или статья получена. |
| `401` | Токен отсутствует или не подходит. Ответ содержит `WWW-Authenticate: Bearer`. |
| `404` | Опубликованная статья по этому ID недоступна. |
| `422` | Параметры запроса не прошли проверку. |
| `503` | В IRIS отсутствует `IRIS_VOICE_KNOWLEDGE_TOKEN`. |
