# Границы модулей

Одно приложение IRIS использует общий FastAPI, React и SQLite. Точки подключения модулей и проверки доступа находятся в `app.main`. Экран получает данные через HTTP и SSE. [Подключение маршрутов](../backend/app/main.py)

| Модуль | Ответственность |
| --- | --- |
| `backend/app/core/crm*.py` и `api/customers.py` | Общие записи клиентов и счетов, чтение данных по адресу и тарифу, поиск и карточка CRM. |
| `backend/app/core/call_ingest.py` и `core/contact_center/` | Сохранение звонков и транскрипций, идентификация абонента, состояния, живые очереди, назначения, бизнес-команды для Voice. |
| `backend/app/core/operations.py` и `api/operations.py` | Списки и детализация звонков и обращений, учёт сотрудников, операции со статусами, корпоративный поток событий. |
| `backend/app/auth/` | Учётные записи, браузерные сессии, ролевые проверки и личные настройки. |
| `backend/app/api/operator.py` | Точка входа браузерного оператора. Получает сотрудника из сессии и использует правила видимости Contact Center и данные CRM. |
| `backend/app/api/contact_center.py` | Внешний операторский API с Bearer-токеном, включая рабочее место, транскрипцию, обращения и SSE. |
| `backend/app/api/contact_center_voice.py` | Сервисный контракт Voice. Отдельный доверенный процесс выполняет SIP, LiveKit, ASR/TTS, генерацию сводок и установку аудиосоединения. |
| `frontend/src/app/`, `layouts/`, `workspaces/` и `features/` | Браузерные маршруты, единая оболочка, экраны двух ролей и переиспользуемые компоненты. |

Назначение вызова оператору и взятие обращения в работу относятся к разным моделям. Техническая фаза звонка меняется после события Voice. Состояния обращения хранятся отдельно от очереди вызовов. [Модель данных](DATA_MODEL.md) · [Интеграция Voice](VOICE_CORE_INTEGRATION.md)
