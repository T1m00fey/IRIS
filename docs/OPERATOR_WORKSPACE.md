# Рабочее место оператора

| Экран | Действия и данные |
| --- | --- |
| `/operator` | Личная главная показывает имя, статус, доступный показатель очереди отдела, личные результаты и список обращений. |
| `/workspace` | Слева предложения и история, в центре сводка, подтверждённые факты, транскрипция, связанные обращения и рабочие заметки. Справа показаны клиент и данные подтверждённого счёта. |
| `/operator/analytics` | Личные звонки, закрытые обращения, длительность и динамика по датам. |
| `/operator/customers/:customerId` | Контакт и счета, подтверждённые доступными рабочими задачами. |
| `/profile` и `/settings` | Профиль, рабочий статус и личные настройки. |

Оператор может принять или отклонить предложение. Принятое назначение переходит в состояние соединения только по подтверждению Voice. Экран отправляет команды удержания, возобновления, перевода и завершения разговора. При недоступной интеграции сервер отклоняет голосовые действия. Управление микрофоном, выбор гарнитуры и проверка звука требуют подключения соответствующих интерфейсов Voice. [Рабочее место](../frontend/src/workspaces/operator/OperatorDesk.tsx) · [Интеграция Voice](VOICE_CORE_INTEGRATION.md)

`GET /api/v1/operator/workspace` возвращает своё назначение, профиль и видимые рабочие данные. `GET /api/v1/operator/events` актуализирует их через SSE с фильтрацией по сотруднику. Приложение также обновляет снимок рабочего места через REST. В доступном звонке можно сохранить свою заметку. После завершения звонка со сводкой оператор может подтвердить её просмотр. [Операторский API](../backend/app/api/operator.py)

`GET /api/v1/operator/analytics` принимает `from_date` и `to_date`. Даты включительны и считаются по Москве. «Принято» учитывает собственные принятые назначения, закрытые обращения считаются по назначенному сотруднику, средняя длительность берётся по завершённым соединениям, а время на линии учитывает пересечение соединения с выбранным периодом. Отсутствие наблюдений отображается пустым состоянием. [Личная аналитика](../frontend/src/workspaces/operator/OperatorPages.tsx)
