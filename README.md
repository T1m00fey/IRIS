# IRIS · Голосовая приёмная SkyNet

**Хакатон SkyNet Signal · Задача № 1**

IRIS — голосовой помощник для первой линии поддержки интернет-провайдера. Абонент звонит на +7 и объясняет, что случилось. Агент уточняет запрос, сверяет данные договора и с согласия абонента передаёт разговор в нужный отдел. Оператор получает карточку с контекстом и продолжает тот же звонок из браузера.

## Сценарий для демо

> «Я оплатил интернет, а он всё равно не работает».

IRIS проверяет платёж и видит открытый инцидент по адресу подключения. Абонент уточняет, что связи нет и на ноутбуке, и на телефоне. Агент зачитывает резюме и после подтверждения направляет звонок в поддержку. Оператор видит, что уже проверено, и может сразу спросить, работает ли интернет по кабелю.

## Блоки проекта

| Папка | Ответственность |
| --- | --- |
| [voice](voice/) | Телефония, голосовой диалог и передача аудио оператору |
| [backend](backend/) | Данные абонента, состояние звонка, очередь обращений и API |
| [frontend](frontend/) | Кабинет оператора со списком звонков, карточкой и подключением к разговору |

Проект на этапе старта. В демо планируем использовать учебные данные договоров, платежей и инцидентов.
