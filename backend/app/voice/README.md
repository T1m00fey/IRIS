# Voice

Первый сценарий проходит от российского номера через входящий SIP-транк LiveKit до агента, который отвечает русским приветствием. Для каждого вызова LiveKit создаёт отдельную комнату. Позже в неё же подключится оператор из браузера.

Сначала проверьте, что мобильный дозванивается до номера и слышит приветствие. Затем подключите двусторонний голосовой диалог, вызовы Core и передачу звонка.

Для городского +7 подходит номер с переадресацией на внешний SIP URI. Например, Novofon документирует такую настройку для входящих и оформление номера +7 812. После активации номера пригодится его фактический номер в формате E.164 и SIP URI проекта LiveKit. Данные доступа храните локально в `.env`.
