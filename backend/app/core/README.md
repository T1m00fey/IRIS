# Core

Core хранит клиентов, лицевые счета, звонки и обращения в общей SQLite. Путь задаёт `DATABASE_PATH`. Во время запуска с `IRIS_DEMO=1` API добавляет синтетические данные. Повторный запуск сохраняет существующие записи.

`GET /api/v1/customers` ищет по имени, телефону и всем лицевым счетам клиента. Ответ содержит данные первого счёта в порядке номеров и время последнего звонка или создания обращения. `GET /api/v1/customers/{customer_id}` возвращает все счета, включая тариф, оборудование, платежи и активные инциденты по адресу каждого счёта. Историю можно запросить через `/api/v1/calls` и `/api/v1/tickets` с фильтрами `customer_id` и `account_number`.

Учебный счёт `100042` даёт сценарий с зачисленным платежом и инцидентом `NET-102`. Счета `100046` и `100047` принадлежат одному клиенту. У них разные адреса, тарифы, платежи и сетевые инциденты.
